# Ubajara Mundo 🌿

Portal independente para divulgação turística de Ubajara, Ceará, Brasil.

## Funcionalidades
- Layout responsivo para celular e computador
- Atrações turísticas da região
- Vitrines demonstrativas de hospedagens e gastronomia
- Busca de atrações
- Idiomas: Português, English e Español
- Links de localização

## Como executar
Abra `index.html` no navegador. Não precisa instalar dependências.

## Publicação
Para publicar usando GitHub Pages, configure **Settings → Pages** no repositório, selecione **Deploy from a branch**, branch `main`, pasta `/(root)`. Quando o Pages estiver ativo, o portal deve ser acessível em `https://alefim.github.io/ss-projetos/ubajara-mundo/`.

**Atenção:** a URL acima só funcionará após ativar o GitHub Pages, e se a configuração do repositório for compatível.

## Antes do lançamento
- Substituir imagens genéricas por fotos reais autorizadas da região
- Substituir contato ilustrativo `contato@example.com` pelo contato oficial do projeto
- Cadastrar e verificar estabelecimentos parceiros
- Conferir informações e horários de atrações com os responsáveis
- Definir privacidade, formulários e políticas antes de receber dados pessoais

> Este é um projeto independente, não oficial da Prefeitura ou do ICMBio. Hospedagens e restaurantes são apenas exemplos.
